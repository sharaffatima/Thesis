\section{Glossary}

The \Gls{latex} typesetting markup language. I can also refer to the glossary item \gls{latex} with a lowercase letter.

\section{Acronyms}

Acronyms can be very useful. I can use the short version \acrshort{cli}, the long version \acrlong{cli}, the full version \acrfull{cli}, or a plural, i.e. \acrshortpl{cli}.

\section{Simultaneous creation of acronym and glossary entry}

There is a custom command that allows the simultaneous definition of acronym and glossary entry. Both can be invoked using the same commands as before, i.e. \gls{pwm} and \acrlong{pwm}.
